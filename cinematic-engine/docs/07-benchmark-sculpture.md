# 07 — Real Benchmark data sculpture

The scene does not contain a frozen score. It invokes the existing analyzer against a normalized public repository identity.

Seven bodies map one-to-one to the current scoring policy:

1. Implementation & Evidence — 20
2. Tests & Reproducibility — 20
3. Evidence & Receipts — 20
4. Continuity & Replay — 15
5. Release-Control Discipline — 15
6. Research & Documentation — 5
7. External / Public Signal — 5

Each category score controls its monolith height and convergence timing. Category DOM values and Canvas geometry are produced from the same `categoryScores` objects. The total remains an em dash during capture and assembly; it appears only after the presentation Gate returns SHOW or REVIEW and the convergence clock settles. A presentation BLOCK reveals no score candidate.

The final rendered evidence records source mode, exact commit SHA, capture timestamp, seven category values, total, presentation decision, and receipt hash. GitHub credentials, when locally available, are used only by the loopback upstream proxy and are absent from the browser and evidence artifacts.
