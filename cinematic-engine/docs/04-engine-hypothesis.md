# 04 — Engine hypothesis

## Hypothesis

If one persistent renderer carries a single trace through three worlds, and if every major motion is driven by product state rather than scroll decoration, a reviewer can understand generation, authority, evidence, consequence, and continuity without explanatory narration.

## Semantic time grammar

Every consequential interaction uses the same five beats:

1. Anticipation — the object is visible but unreleased.
2. Action — a request or evidence capture begins.
3. Consequence — authoritative state or computed category values alter physics.
4. Settle — the scene resolves into a readable terminal configuration.
5. Persistent trace — receipt, withheld trace, or evidence hash remains.

Ambient motion is low-frequency and represents field pressure, boundary stability, or evidence circulation. Interactive motion bends the field but cannot move authority. State motion starts after data. Route motion crossfades/morphs worlds without a black curtain. Reduced motion renders one meaningful settled frame with no continuous RAF.

## Success test

The hypothesis passes only if video shows, without narration: possibility approaches; authority holds; SHOW crosses; REVIEW suspends; BLOCK returns or extinguishes; ERROR fails closed; seven values converge; total settles; Axiom witnesses.
