## BLOCK / SILENCE

The candidate impacts the authority field, returns toward the unreleased side while energy decays, and leaves a red audit trace. SILENCE is shown as withheld release with audit preservation—not deletion and not a broken UI.

## ERROR

The deliberate local transport fault creates no Gate state pair, no receipt, and no released content. The candidate stays behind a diagnostic perimeter. The terminal labels this as ERROR / NO DECISION / RELEASE DENIED.
