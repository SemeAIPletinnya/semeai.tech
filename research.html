Evidence posture

Implementation artifacts

Versioned software, schemas, tests, receipts, public repository history, and running product surfaces can be inspected.

Active inquiry

Release authority, continuity, replay, bounded repository evidence, and deterministic decision traces remain subjects of engineering and research.

Unsupported claims

No universal AI-safety proof, AGI measure, hallucination guarantee, security certification, or compliance certification is claimed.

Retrieval is not truth. A commit is implementation evidence, not proof of idea origin. The Repository Evidence Benchmark admits bounded visible evidence and controls result display only.

CLAIM CLASSIFICATION

Evidence changes what may be said.

MEASURED
A value captured by a named method, fixture, and bounded observation.
DEMONSTRATED
A behavior reproduced by an inspectable implementation or test.
OBSERVED
A recorded outcome without enough cases for a general claim.
HYPOTHESIS
A direction requiring further implementation or evaluation.
HISTORICAL FRAMING
Preserved prior language that is not promoted into a current technical claim.
