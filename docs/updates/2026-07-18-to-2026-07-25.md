## Architecture trace

The public architecture documented by the current repository is:

1. generation produces a candidate;
2. evidence, business data, policy, and context are evaluated before release;
3. the runtime Gate remains release authority;
4. public presentation vocabulary maps to canonical release states;
5. receipts retain the decision trace;
6. the Benchmark separately evaluates visible repository evidence and controls only result presentation;
7. the Book explains implementation and first principles;
8. Research records evidence and claim boundaries.

Metadata, popularity, and visual rank do not become release authority.
